A SELL-SIDE PACKAGE BUILT ON SYNTHETIC DATA · NO CLIENT ENGAGEMENT REPRESENTED

IN THIS CASE

The figure registerThe add-back disciplineThe package

This worked example uses synthetic data for a mechanical services company. It demonstrates the package structure and does not represent a client engagement.

A lower-middle-market sale puts four documents in front of a buyer over about six weeks. A teaser goes out first, a management presentation follows, a data room opens, and a model extract answers the questions the presentation raised. Each document is usually built by a different person at a different moment, and each one restates the same operating figures.

Different treatments of the same add-back can produce different adjusted EBITDA figures in the teaser and model extract. Documenting those adjustments in one register gives the seller a consistent calculation and supporting evidence for diligence.

The figure register

A shared register records the financial figures used across the package. Each entry identifies the definition, reporting period, source workbook cell, and documents using that figure.

The add-back discipline

Every adjusted EBITDA add-back in the register includes its amount, justification, and supporting evidence. An owner compensation normalization names the market salary it was benchmarked against. A one-time legal settlement names the document that proves it was one time.

The package

  • A one-page anonymous teaser sized for a first look
  • A management presentation carrying the operating story and the growth case
  • A data room index mapping every claim to the document that supports it
  • A model extract showing the arithmetic behind the headline figures
  • A key figure register governing all four

The teaser, management presentation, data room, and model extract used the same adjusted EBITDA definition and supporting adjustments.
