ENGAGEMENT · CUSTOM UNDERWRITING TOOL · SECTION 8 SFH

An address and a price produce a sourced proforma and a decision memo.

A REPEAT BUYER OF SECTION 8 SINGLE-FAMILY RENTALS

IN THIS CASE

The suppression ruleThe package

A repeat buyer of Section 8 single-family rentals spent an evening underwriting each deal by hand. Assumptions varied between properties, making the resulting returns difficult to compare.

The tool takes an address and a price. It returns a populated rental proforma, a one-page decision memo, and a provenance record naming the source behind each required input. The first working version shipped the same day the job was awarded.

The suppression rule

Each required input has a source record. Rent comes from the published HUD fair market rent schedule for the county and bedroom count; taxes come from the assessor record. The tool identifies missing sources and withholds the recommendation until the required inputs are documented.

The package

  • A command-line runner and a browser interface over one underwriting engine
  • A local database of HUD fair market rents, rebuilt on the annual publication cycle
  • Per-deal output folders holding the proforma, the memo, and the provenance record for every read
  • A regression suite that runs the engine with the network disabled to check whether code changes alter the expected results on the test cases

The buyer receives a recommendation only when the required inputs have documented sources.
