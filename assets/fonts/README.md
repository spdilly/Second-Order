# Website typography

Space Grotesk (display) and Manrope (body) are self-hosted variable fonts. Both are distributed under the SIL Open Font License; the full licenses are included beside the fonts.

Sources:
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- https://github.com/google/fonts/tree/main/ofl/manrope

Downloaded September 9, 2026. No external font request is needed to render the website.
